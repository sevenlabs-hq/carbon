# Carbon OnChain Labs DEX V2 Decoder

Decodes OnChain Labs DEX V2 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `proVF4pMXVaYqmy4NjniPh4pqKNfMmsihgd4wdkCX3u`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/onchain-labs-dex-v2

```sh
cargo add carbon-onchain-labs-dex-v2-decoder
```
