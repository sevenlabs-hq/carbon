# Carbon Wavebreak Program Decoder

Decodes Wavebreak Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `waveQX2yP3H1pVU8djGvEHmYg8uamQ84AuyGtpsrXTF`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/wavebreak

```sh
cargo add carbon-wavebreak-decoder
```
