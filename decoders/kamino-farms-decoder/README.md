# Carbon Kamino Farms Decoder

Decodes Kamino Farms instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `FarmsPZpWu9i7Kky8tPN37rs2TpmMrAZrC7S7vJa91Hr`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/kamino-farms

```sh
cargo add carbon-kamino-farms-decoder
```
