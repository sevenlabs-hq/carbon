# Carbon Openbook V2 Decoder

Decodes Openbook V2 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `opnb2LAfJYbRMAHHvqjCwQxanZn7ReEHp1k81EohpZb`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/openbook-v2

```sh
cargo add carbon-openbook-v2-decoder
```
