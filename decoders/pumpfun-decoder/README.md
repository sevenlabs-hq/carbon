# Carbon Pumpfun Decoder

Decodes Pumpfun instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `6EF8rrecthR5Dkzon8Nwu78hRvfCKubJ14M5uBEwF6P`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/pumpfun

```sh
cargo add carbon-pumpfun-decoder
```
