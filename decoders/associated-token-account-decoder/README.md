# Carbon Associated Token Account program Decoder

Decodes Associated Token Account program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `ATokenGPvbdGVxr1b2hvZbsiqW5xWH25efTNsLJA8knL`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/associated-token-account

```sh
cargo add carbon-associated-token-account-decoder
```
