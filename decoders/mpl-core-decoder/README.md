Decodes MPL Core instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `CoREENxT6tW1HoK8ypY1SxRMZTcVPm7R94rH4PZNhX7d`.
