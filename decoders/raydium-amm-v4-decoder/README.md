# Carbon Raydium AMM V4 Decoder

Decodes Raydium AMM V4 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `675kPX9MHTjS2zt1qfr1NYHuzeLXfQM9H24wFSUt1Mp8`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/raydium-amm-v4

```sh
cargo add carbon-raydium-amm-v4-decoder
```
