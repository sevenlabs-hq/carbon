# Carbon Heaven program Decoder

Decodes Heaven program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `HEAVENoP2qxoeuF8Dj2oT1GHEnu49U5mJYkdeC8BAX2o`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/heaven

```sh
cargo add carbon-heaven-decoder
```
