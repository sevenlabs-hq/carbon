# Carbon Kamino Lending Decoder

Decodes Kamino Lending instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `KLend2g3cP87fffoy8q1mQqGKjrxjC8boSyAYavgmjD`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/kamino-lending

```sh
cargo add carbon-kamino-lending-decoder
```
