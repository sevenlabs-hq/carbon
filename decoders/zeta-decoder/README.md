# Carbon Zeta Program Decoder

Decodes Zeta Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `ZETAxsqBRek56DhiGXrn75yj2NHU3aYUnxvHXpkf3aD`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/zeta

```sh
cargo add carbon-zeta-decoder
```
