# Carbon Raydium Stable Swap Decoder

Decodes Raydium Stable Swap instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `5quBtoiQqxF9Jv6KYKctB59NT3gtJD2Y65kdnB1Uev3h`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/raydium-stable-swap

```sh
cargo add carbon-raydium-stable-swap-decoder
```
