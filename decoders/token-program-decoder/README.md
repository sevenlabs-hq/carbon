# Carbon Token Program Decoder

Decodes Token Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/token-program

```sh
cargo add carbon-token-program-decoder
```
