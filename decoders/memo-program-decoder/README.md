# Carbon Memo Program Decoder

Decodes Memo Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/memo-program
