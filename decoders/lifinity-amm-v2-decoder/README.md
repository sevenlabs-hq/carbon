Decodes Lifinity AMM V2 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `2wT8Yq49kHgDzXuPxZSaeLaH1qbmGXtEyPy64bL7aD3c`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/lifinity-amm-v2
