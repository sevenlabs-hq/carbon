# Carbon Phoenix V1 Decoder

Decodes Phoenix V1 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `PhoeNiXZ8ByJGLkxNfZRnkUfjvmuYqLR89jjFHGqdXY`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/phoenix-v1

```sh
cargo add carbon-phoenix-v1-decoder
```
