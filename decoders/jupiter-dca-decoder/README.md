# Carbon Jupiter DCA Decoder

Decodes Jupiter DCA instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `DCA265Vj8a9CEuX1eb1LWRnDT7uK6q1xMipnNyatn23M`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/jupiter-dca

```sh
cargo add carbon-jupiter-dca-decoder
```
