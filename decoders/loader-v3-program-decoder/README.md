# Carbon Loader v3 program Decoder

Decodes Loader v3 program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `BPFLoaderUpgradeab1e11111111111111111111111`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/loader-v3-program

```sh
cargo add carbon-loader-v3-program-decoder
```
