# Carbon Jupiter Limit Order 2 Decoder

Decodes Jupiter Limit Order 2 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `j1o2qRpjcyUwEvwtcfhEQefh773ZgjxcVRry7LDqg5X`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/jupiter-limit-order-2
