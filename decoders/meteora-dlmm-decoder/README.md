# Carbon Meteora DLMM Decoder

Decodes Meteora DLMM instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `LBUZKhRxPF3XUpBCjp4YzTKgLccjZhTSDM9YuVaPwxo`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/meteora-dlmm

```sh
cargo add carbon-meteora-dlmm-decoder
```
