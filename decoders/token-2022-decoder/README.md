# Carbon Carbon Token 2022 Decoder

Decodes Carbon Token 2022 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/token-2022

```sh
cargo add carbon-token-2022-decoder
```
