# Carbon Meteora vault program Decoder

Decodes Meteora vault program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `24Uqj9JCLxUeoC3hGfh5W3s9FM9uCHDS2SG3LYwBpyTi`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/meteora-vault

```sh
cargo add carbon-meteora-vault-decoder
```
