# Carbon OKX DEX Decoder

Decodes OKX DEX instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `6m2CDdhRgxpH4WjvdzxAYbGxwdGUz5MziiL5jek2kBma`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/okx-dex

```sh
cargo add carbon-okx-dex-decoder
```
