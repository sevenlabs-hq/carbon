# Carbon Carbon PancakeSwap Decoder

Decodes Carbon PancakeSwap instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `HpNfyc2Saw7RKkQd8nEL4khUcuPhQ7WwY1B2qjx8jxFq`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/pancake-swap

```sh
cargo add carbon-pancake-swap-decoder
```
