# Carbon Virtuals Program Decoder

Decodes Virtuals Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `5U3EU2ubXtK84QcRjWVmYt9RaDyA8gKxdUrPFXmZyaki`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/virtuals

```sh
cargo add carbon-virtuals-decoder
```
