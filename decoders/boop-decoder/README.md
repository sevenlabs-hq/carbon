# Carbon Boop program Decoder

Decodes Boop program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `boop8hVGQGqehUK2iVEMEnMrL5RbjywRzHKBmBE7ry4`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/boop

```sh
cargo add carbon-boop-decoder
```
