# Carbon Raydium Liquidity Locking Decoder

Decodes Raydium Liquidity Locking instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `LockrWmn6K5twhz3y9w1dQERbmgSaRkfnTeTKbpofwE`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/raydium-liquidity-locking

```sh
cargo add carbon-raydium-liquidity-locking-decoder
```
