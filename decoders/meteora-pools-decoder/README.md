# Carbon Meteora Pools Program Decoder

Decodes Meteora Pools Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `Eo7WjKq67rjJQSZxS6z3YkapzY3eMj6Xy8X5EQVn5UaB`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/meteora-pools

```sh
cargo add carbon-meteora-pools-decoder
```
