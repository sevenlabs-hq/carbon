# Carbon Marinade Finance Decoder

Decodes Marinade Finance instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `MarBmsSgKXdrN1egZf5sqe1TMai9K1rChYNDJgjq7aD`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/marinade-finance

```sh
cargo add carbon-marinade-finance-decoder
```
