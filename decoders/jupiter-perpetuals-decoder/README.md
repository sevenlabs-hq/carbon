# Carbon Jupiter Perpetuals Decoder

Decodes Jupiter Perpetuals instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `PERPHjGBqRHArX4DySjwM6UJHiR3sWAatqfdBS2qQJu`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/jupiter-perpetuals

```sh
cargo add carbon-jupiter-perpetuals-decoder
```
