# Carbon Bubblegum Program Decoder

Decodes Bubblegum Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `BGUMAp9Gq7iTEuizy4pqaxsTyUCBK68MDfK752saRPUY`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/bubblegum

```sh
cargo add carbon-bubblegum-decoder
```
