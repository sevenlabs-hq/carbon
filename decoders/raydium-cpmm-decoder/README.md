# Carbon Raydium CPMM Decoder

Decodes Raydium CPMM instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/raydium-cpmm

```sh
cargo add carbon-raydium-cpmm-decoder
```
