# Carbon Meteora DBC Decoder

Decodes Meteora DBC instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `dbcij3LWUppWqq96dh6gJWwBifmcGfLSB5D4DuSMaqN`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/meteora-dbc

```sh
cargo add carbon-meteora-dbc-decoder
```
