# Carbon Vertigo DEX Program Decoder

Decodes Vertigo DEX Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `vrTGoBuy5rYSxAfV3jaRJWHH6nN9WK4NRExGxsk1bCJ`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/vertigo

```sh
cargo add carbon-vertigo-decoder
```
