# Carbon Moonshot Decoder

Decodes Moonshot instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `MoonCVVNZFSYkqNXP6bxHLPL6QQJiMagDL3qcqUQTrG`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/moonshot

```sh
cargo add carbon-moonshot-decoder
```
