# Carbon Raydium Launchpad Decoder

Decodes Raydium Launchpad instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `LanMV9sAd7wArD4vJFi2qDdfnVhFxYSUg6eADduJ3uj`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/raydium-launchpad

```sh
cargo add carbon-raydium-launchpad-decoder
```
