# Carbon Carbon BonkSwap Decoder

Decodes Carbon BonkSwap instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `BSwp6bEBihVLdqJRKGgzjcGLHkcTuzmSo1TQkHepzH8p`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/bonkswap

```sh
cargo add carbon-bonkswap-decoder
```
