# Carbon Stabble Stable Swap Decoder

Decodes Stabble Stable Swap instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `swapNyd8XiQwJ6ianp9snpu4brUqFxadzvHebnAXjJZ`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/stabble-stable-swap
