# Carbon MarginfiV2 Decoder

Decodes MarginfiV2 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `MFv2hWf31Z9kbCa1snEPYctwafyhdvnV7FZnsebVacA`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/marginfi-v2

```sh
cargo add carbon-marginfi-v2-decoder
```
