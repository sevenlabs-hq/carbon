# Carbon Dflow Aggregator V4 Decoder

Decodes Dflow Aggregator V4 instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `DF1ow4tspfHX9JwWJsAb9epbkA8hmpSEAtxXy1V27QBH`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/dflow-aggregator-v4
