# Carbon Jupiter Swap Decoder

Decodes Jupiter Swap instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `JUP6LkbZbjS1jKKwapdHNy74zcZ3tLUZoi5QNyVTaV4`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/jupiter-swap

```sh
cargo add carbon-jupiter-swap-decoder
```
