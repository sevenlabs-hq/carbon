# Carbon Address lookup table program Decoder

Decodes Address lookup table program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `AddressLookupTab1e1111111111111111111111111`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/address-lookup-table

```sh
cargo add carbon-address-lookup-table-decoder
```
