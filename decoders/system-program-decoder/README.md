# Carbon System Program Decoder

Decodes System Program instructions and accounts on Solana into typed Rust, for use in a [Carbon](https://github.com/sevenlabs-hq/carbon) pipeline. Program ID: `11111111111111111111111111111111`.

Docs, with a runnable example and every instruction, account and type: https://carbon.sevenlabs.org/decoders/system-program

```sh
cargo add carbon-system-program-decoder
```
